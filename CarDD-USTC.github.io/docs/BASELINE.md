# CarDD DCN+ Baseline Documentation

## 1. Repository Audit Information
* **Original Repository URL**: https://github.com/CarDD-USTC/CarDD-USTC.github.io.git
* **Commit Hash Used**: 1cc8e0fdc41c7aea7300475ed2073b373ee278bf
* **Baseline Architecture**: Mask R-CNN with ResNet-101 and Deformable Convolutional Networks (DCN), FPN, and DConv.
* **Original Configuration File**: `code/CarDD_detection/configs/car_damage/DCN_plus_cfg.py`

## 2. Environment Requirements
* **Framework**: Based on MMDetection (2.x era code)
* **Python**: 3.8 (Targeted legacy environment)
* **PyTorch**: 1.7.0
* **CUDA**: 11.0
* **MMCV**: 1.7.0

## 3. Dataset Configuration
* **Expected Dataset Path**: `data/CarDD_COCO/` (as mapped from `/root/autodl-fs/data/CarDD_COCO/` in the original config)
* **Structure expected by baseline**:
  ```
  data/CarDD_COCO/
  ├── annotations/
  │   ├── instances_train2017.json
  │   ├── instances_val2017.json
  │   └── instances_test2017.json

  ├── val2017/

  ```

## 4. Entry Points
The baseline utilizes standard MMDetection scripts found in `code/CarDD_detection/tools/`.

* **Training Command**:
  ```bash
  python code/CarDD_detection/tools/train.py code/CarDD_detection/configs/car_damage/DCN_plus_cfg.py
  ```

* **Testing Command**:
  ```bash
  python code/CarDD_detection/tools/test.py code/CarDD_detection/configs/car_damage/DCN_plus_cfg.py <CHECKPOINT_PATH> --eval bbox segm
  ```

* **Inference Command**:
  ```bash
  python code/CarDD_detection/tools/inference.py --img <IMG_PATH> --config code/CarDD_detection/configs/car_damage/DCN_plus_cfg.py --checkpoint <CHECKPOINT_PATH>
  ```
